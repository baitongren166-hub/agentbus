# 飞书接入：初次配置（给会用浏览器的 agent 照着做）

目标：在主人的飞书开放平台建一个企业自建应用，当 agentbus 的机器人。主人出门时在手机飞书里选项目、开新聊天、跟主位聊。
用主人已经登录飞书的浏览器操作；没登录就停下来请主人登录，不替主人登录、不输入任何密码或验证码。你没法操作浏览器的话，就把每一步讲给主人、让主人自己点，你在对话里陪着确认。
**App Secret 不复制、不显示、不写进任何文件或回复**：第三步用系统弹窗让主人自己粘贴。全程不用主人打开 agentbus 界面填东西。

## 第一步：建应用、起名、换图标
1. 打开 https://open.feishu.cn/app →「创建企业自建应用」。
   - 应用名称：`{bot_name}`（agentbus 按「Agentbus-电脑名」自动起的，主人想改可以改）
   - 应用描述：在飞书上给电脑里的 agent 派活、看进度
   - 应用图标：`{icon}`（agentbus 的星球图标，512×512 PNG）
2. 已经建好的应用要改名/换图标：「基础信息 → 凭证与基础信息」，「国际化配置」旁的编辑图标改名称；「综合信息」旁的编辑图标 → 点当前图标选图 → 保存，回到「综合信息」再点一次保存。
3. 「添加应用能力」→ 加上**机器人**（机器人用的就是应用的名称和图标）。

## 第二步：开权限（「权限管理」，搜权限码开通）
`im:message`、`im:message.p2p_msg:readonly`、`im:message.group_at_msg:readonly`、`im:message.group_msg`、`im:chat`、`im:resource`、`cardkit:card:write`

## 第三步：存密钥，电脑连上飞书
运行 `agentbus feishu setup <App ID>`：macOS 会弹出隐藏输入的系统窗口。Windows 和 Linux 请让主人在自己的终端里运行命令，用隐藏输入粘贴 App Secret。密钥由 agentbus 存到本机的凭证存储。
然后每隔 30 秒运行一次 `agentbus feishu status`，等它显示「长连接：已连上」再做下一步（最多等 15 分钟；等不到就停下来告诉主人）。
飞书要检测到电脑连上了，长连接模式才能保存。

## 第四步：事件和回调（都选「使用长连接接收」）
- 「事件与回调 → 事件配置」：订阅方式选长连接，保存；添加事件「接收消息 v2.0」（`im.message.receive_v1`）。
- 「事件与回调 → 回调配置」：订阅方式选长连接，保存；添加回调「卡片回传交互」（`card.action.trigger`）。
- 提示「未检测到应用连接」就等 30 秒再保存。

## 第五步：发布
「应用发布 → 版本管理与发布」→ 创建版本（版本号比线上高），可用范围只选主人本人 → 保存 → 免审就「确认发布」，要审核就「申请线上发布」等管理员。

## 最后
运行 `agentbus feishu code` 拿配对码，告诉主人：在飞书里搜机器人「{bot_name}」，私聊发这串配对码完成绑定。
再告诉主人怎么用：
- 私聊机器人随便发一句，弹出选项目卡片；选好项目后选模式（主位助理要选主位，群聊要选拉谁），点「进群开聊」。
- 一个「项目 + 模式（+ 主位）」一个群，群名模式在前：「主位助理 · GPT · 📁 示例项目」「派活 · 📁 示例项目」「群聊 · 📁 示例项目」。
  群头像：主位助理是主位的 Q 版头像，派活是一圈队员头像，群聊是拉进来的那几位拼在一起。
- 进群后点「新建话题」写第一句话就开一个新对话；主位助理群里只跟主位聊，派活群里写队员名字或简称就派给他。
- 出门前在悬浮窗或私聊里打开「出门模式」，电脑就不会睡。
